# Война Клеточек

Крестики-нолики в милом пастельном стиле: **Кошечка** с бантиком против
**Зайки** в розовом капюшоне. Статический сайт без сборки и зависимостей —
достаточно открыть `index.html`.

## Возможности

- **Заставка** с покачивающейся Кошечкой, названием и розовой присказкой
  (восемь вариантов, выпадает случайная).
- **Пастельный фон** на canvas: градиент, горошек и плывущие вверх сердечки,
  звёздочки и бантики. Всё рисуется кодом — картинок в проекте нет.
- **Две героини**: Кошечка (ходит первой) и Зайка. Обе нарисованы вектором
  прямо в разметке, это авторские рисунки, а не чьи-то официальные изображения.
- **Два режима**: против подружки-бота или вдвоём за одним экраном.
- **Три сложности**, переключаются и в меню, и прямо посреди партии:
  - *Котёнок* — ходит почти наугад;
  - *Подружка* — минимакс с ошибками примерно в 28 % ходов;
  - *Королева бантиков* — полный минимакс с альфа-бета отсечением, проиграть
    не может (проверено 3000 партий против случайного игрока: 0 поражений).
- **Финал раунда** — карточка «Награда получена!», выигрышные клетки желтеют,
  а по линии протягивается розовая ленточка.
- **Звук** синтезируется через WebAudio, внешних файлов нет: мягкие «пуфы» на
  ход, колокольчик на собранную линию, радостная трель на победу.
  Отключается кнопкой, состояние запоминается.
- **Счёт матча и сложность** хранятся в `localStorage`.
- **Доступность**: клавиши `1`–`9` для ходов, `R` — новый раунд, `Esc` закрывает
  карточку награды, `Enter` запускает игру с заставки; у клеток есть
  `aria-label`, есть поддержка `prefers-reduced-motion`.

## Структура

```
index.html               разметка + векторные фигурки героинь
assets/css/style.css     оформление: пастель, скругления, мягкие тени, адаптив
assets/js/world.js       фон на canvas: горошек и плывущие сердечки
assets/js/sfx.js         синтез звука через WebAudio
assets/js/ai.js          минимакс и уровни сложности бота
assets/js/game.js        состояние партии, отрисовка, счёт
```

## Запуск

```bash
# просто открыть файл
open index.html

# или поднять локальный сервер
npx http-server -p 8000 .
```

Шрифты Pacifico и M PLUS Rounded 1c подгружаются с Google Fonts — оба с
кириллицей. Без сети подставляются системные, вёрстка не ломается.
