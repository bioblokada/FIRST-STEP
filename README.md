# Война Клеточек

Объёмные крестики-нолики с двумя стилями оформления: **Minecraft** (Стив против
крипера) и **милый пастельный** (Кошечка против Зайки). Статический сайт без
сборки и зависимостей — достаточно открыть `index.html`.

## Возможности

- **Два стиля** переключаются на лету: на заставке, в настройках и кнопкой 🎨
  в шапке. Меняется всё — палитра, шрифты, фигурки, фон, звуки и тексты
  интерфейса. Выбор запоминается и применяется до отрисовки, без мигания.
- **Объёмное поле**: плита наклонена в перспективе, блоки выступают над ней
  настоящими гранями, выигрышные поднимаются выше всех.
- **Вращение мышкой**: поле можно потянуть и осмотреть с любой стороны
  (наклон 2–74°, поворот ±52°). Двойной клик или кнопка «Вернуть вид»
  возвращают исходный ракурс. Короткий клик по-прежнему ставит фигурку —
  ход и перетаскивание различаются по смещению курсора.
- **Фон рисуется кодом** на canvas: блочный мир с солнцем, облаками, рельефом
  и деревьями — или пастельный градиент с горошком и плывущими сердечками.
- **Два режима**: против бота или вдвоём за одним экраном.
- **Три сложности**, переключаются и в меню, и прямо посреди партии. Верхний
  уровень — полный минимакс с альфа-бета отсечением, проиграть не может
  (проверено 3000 партий против случайного игрока: 0 поражений).
- **Клетки проигравшего сгорают**: ровно за три секунды они вспыхивают
  костром на canvas, фигурка выгорает снизу вверх, а блок оседает в плиту
  обугленной ямой. Итоговое окно ждёт, пока костёр не догорит.
- **Звук** синтезируется через WebAudio, внешних файлов нет: свой набор на
  каждую тему плюс общий костёр — поджиг, гул, потрескивание и обрушение
  головёшек. Отключается кнопкой, состояние запоминается.
- **Счёт матча, сложность и стиль** хранятся в `localStorage`. Если браузер
  запрещает доступ к данным сайта (приватное окно, блокировка cookie,
  песочница iframe), игра всё равно запускается — просто ничего не помнит.
- **Доступность**: клавиши `1`–`9` для ходов, `R` — новый раунд, `Esc`
  закрывает итоговое окно, `Enter` запускает игру с заставки; у клеток есть
  `aria-label`, есть поддержка `prefers-reduced-motion`.

## Структура

```
index.html               разметка, общая для обеих тем, и фигурки всех героев
assets/css/style.css     токены двух тем и общая вёрстка, включая 3D-поле
assets/js/store.js       безопасная обёртка над localStorage
assets/js/themes.js      конфигурация тем: фигурки, тексты, уровни, реплики
assets/js/world.js       фон на canvas: блочный мир или пастель
assets/js/sfx.js         синтез звука, отдельный набор на каждую тему
assets/js/fire.js        частицы костра над клетками проигравшего
assets/js/orbit.js       вращение поля мышкой и пальцем
assets/js/ai.js          минимакс и уровни сложности бота
assets/js/game.js        тема, состояние партии, отрисовка, счёт
```

## Запуск

```bash
# просто открыть файл
open index.html

# или поднять локальный сервер
npx http-server -p 8000 .
```

Шрифты подгружаются с Google Fonts: Pixelify Sans и Press Start 2P для стиля
Minecraft, Pacifico и M PLUS Rounded 1c для пастельного. Все четыре с
кириллицей; без сети подставляются системные, вёрстка не ломается.

Фигурки нарисованы в разметке — это авторские рисунки, а не чьи-то
официальные изображения.
