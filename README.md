# Война Клеточек

Крестики-нолики в стиле Minecraft: **Стив** против **крипера** на поле из девяти
блоков. Статический сайт без сборки и зависимостей — достаточно открыть
`index.html`.

## Возможности

- **Главное меню** как в игре: логотип, качающаяся жёлтая сплэш-строка (восемь
  вариантов, выпадает случайно) и кнопка «Начать игру».
- **Блочный мир на фоне**: небо с градиентом, квадратное солнце, плывущие
  пиксельные облака, рельеф из травы, земли и камня, деревья. Всё рисуется
  процедурно на canvas — картинок в проекте нет.
- **Два скина**: Стив (ставит блок первым) и крипер. Оба — пиксель-арт 8×8,
  собранный из SVG-прямоугольников.
- **Два режима**: против мод-бота или вдвоём за одним экраном.
- **Три сложности**, переключаются и в меню, и прямо посреди партии:
  - *Мирный* — ставит блоки почти наугад;
  - *Нормальный* — минимакс с ошибками примерно в 28 % ходов;
  - *Хардкор* — полный минимакс с альфа-бета отсечением, проиграть не может
    (проверено 3000 партий против случайного игрока: 0 поражений).
- **Финал раунда** оформлен как ачивка: «Достижение получено!», выигрышные
  клетки становятся золотыми блоками.
- **Поле объёмное**: плита наклонена в перспективе, поставленные блоки
  выступают над ней настоящими торцами, выигрышные поднимаются выше всех,
  а пустые ячейки читаются как углубления. Блок под курсором приподнимается.
- **Клетки проигравшего сгорают**: ровно за три секунды они вспыхивают
  пиксельным костром на canvas, фигурка выгорает снизу вверх и чернеет,
  а сам блок оседает в плиту и остаётся обугленной ямой. Итоговое окно ждёт,
  пока костёр не догорит.
  При `prefers-reduced-motion` огонь пропускается.
- **Звук** синтезируется через WebAudio, внешних файлов нет: стук блока, шаг
  моба, подбор опыта, звук нового уровня, шипение и взрыв крипера.
  Отключается кнопкой, состояние запоминается. У костра свой звук: поджиг,
  ровный гул на все три секунды, потрескивание и обрушение головёшек в конце.
- **Счёт матча и сложность** хранятся в `localStorage`.
- **Доступность**: клавиши `1`–`9` для ходов, `R` — новый раунд, `Esc` закрывает
  окно ачивки, `Enter` запускает игру из меню; у клеток есть `aria-label`, есть
  поддержка `prefers-reduced-motion`.

## Структура

```
index.html               разметка + пиксель-арт скинов (SVG 8×8)
assets/css/style.css     оформление: блоки, скошенные рамки, текстуры, адаптив
assets/js/world.js       процедурный блочный мир на canvas
assets/js/fire.js        частицы костра над клетками проигравшего
assets/js/sfx.js         синтез звука через WebAudio
assets/js/ai.js          минимакс и уровни сложности бота
assets/js/game.js        состояние партии, отрисовка, счёт
```

## Запуск

```bash
# просто открыть файл
open index.html

# или поднять локальный сервер
npx http-server -p 8000 .
```

Шрифты Pixelify Sans и Press Start 2P подгружаются с Google Fonts — оба с
кириллицей. Без сети подставляются системные, вёрстка не ломается.
