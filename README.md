# Война Клеточек

Крестики-нолики в стиле «Звёздных войн»: Альянс повстанцев против Галактической
Империи. Статический сайт без сборки и зависимостей — достаточно открыть
`index.html`.

## Возможности

- **Вступительный кроул** в духе оригинальных титров (можно пропустить кликом).
- **Две стороны**: эмблема повстанцев (ходит первой) и имперский герб.
- **Два режима**: против дроида или вдвоём за одним экраном.
- **Три уровня дроида**:
  - *Падаван* — ходит почти наугад;
  - *Рыцарь-джедай* — минимакс с ошибками примерно в 28 % ходов;
  - *Магистр* — полный минимакс с альфа-бета отсечением, проиграть не может
    (проверено 3000 партий против случайного игрока: 0 поражений).
- **Анимация победы**: выигрышная линия «прожигается» лучом светового меча —
  синим за Альянс, красным за Империю.
- **Звук** синтезируется через WebAudio, внешних файлов нет: выстрел бластера,
  залп турболазера, зажигание меча, фанфара и имперский мотив на поражение.
  Отключается кнопкой, состояние запоминается.
- **Счёт матча** хранится в `localStorage`.
- **Звёздное небо** на canvas с мерцанием и редкими прыжками в гиперпространство.
- **Доступность**: клавиши `1`–`9` для ходов, `R` — новый раунд, `Esc` закрывает
  итоговое окно; у клеток есть `aria-label`, есть поддержка
  `prefers-reduced-motion`.

## Структура

```
index.html               разметка + SVG-спрайт эмблем
assets/css/style.css     оформление, адаптив, анимации
assets/js/starfield.js   звёздное поле на canvas
assets/js/sfx.js         синтез звука через WebAudio
assets/js/ai.js          минимакс и уровни сложности дроида
assets/js/game.js        состояние партии, отрисовка, счёт
```

## Запуск

```bash
# просто открыть файл
open index.html

# или поднять локальный сервер
npx http-server -p 8000 .
```

Шрифты Orbitron и Share Tech Mono подгружаются с Google Fonts; без сети
подставляются системные моноширинные — вёрстка не ломается.
