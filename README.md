# Ну, погоди! Семейная

Ремейк электронной игры «Электроника ИМ-02» на одном HTML-файле для пяти членов семьи.
У каждого игрока свой цвет, свои предметы, своя «ловушка», свои звуки и фразы.

**Запуск:** откройте `index.html` в браузере (двойным кликом или через GitHub Pages).

**Фото лиц:** положите `photos/1.jpg … 5.jpg` (см. `photos/README.md`) или загрузите кнопкой в игре.

**Управление:** `Q`/`A` — левые лотки, `P`/`L` или `↑`/`↓` — правые, `Enter` — старт, `Esc` — пауза.
На телефоне: круглые кнопки или нажатие на четверть экрана.
