# Протокол проверки: что снять и где

Здесь перечислены **конкретные показатели** и **конкретные места**, где они берутся.
Ни один из них я снять не могу: сайт закрыт сетевой политикой, а к панелям вебмастера
и аналитики у меня нет доступа. Выдумывать эти цифры я не буду — на выдуманных данных
принимаются неправильные решения, и это хуже, чем отсутствие данных.

Порядок шагов не случайный: каждый следующий опирается на предыдущий.

---

## Шаг 0. Разблокировать домен — блокирует всё остальное

Сейчас `fairwinds.school` закрыт egress-политикой окружения: и `curl`, и встроенная
загрузка страниц получают отказ `403 CONNECT`. Это настройка среды Claude Code, изнутри
сессии она не меняется.

**Что сделать:** в настройках окружения Claude Code на web (claude.ai/code → настройки
окружения → сетевая политика / разрешённые домены) добавить `fairwinds.school`.
Документация: https://code.claude.com/docs/en/claude-code-on-the-web

**Важно:** изменение политики, скорее всего, подхватится только новой сессией — после правки
запустите новую и вернитесь к этой задаче. Файлы в репозитории сохранятся.

**Что это даст:** разделы A и B из `01-findings.md` схлопнутся в один настоящий аудит
с доказательствами по каждой строке.

## Шаг 1. Панели вебмастера — база, без которой всё остальное гадание

### Яндекс.Вебмастер (webmaster.yandex.ru) — приоритетный, у вас русскоязычная аудитория

| Что снять | Где именно |
|---|---|
| Число страниц в поиске | Индексирование → Страницы в поиске → «Все страницы» |
| Исключённые страницы и **причина** по каждой | Индексирование → Страницы в поиске → «Исключённые страницы» |
| Ошибки и рекомендации | Диагностика → Диагностика сайта |
| Показы, клики, средняя позиция, CTR за 90 дней | Поисковые запросы → Статистика запросов |
| Какие запросы уже приносят показы | Поисковые запросы → Управление группами |
| Какой регион присвоен сайту | Информация о сайте → Региональность |
| Корректность robots.txt | Инструменты → Анализ robots.txt |
| Коды ответа ключевых URL | Инструменты → Проверка ответа сервера |

⚠️ Отчёт «Статистика запросов» — единственный честный источник ваших нынешних позиций.
Всё, что скажет о позициях кто угодно без доступа к этому отчёту (включая меня), — оценка, а не факт.

### Google Search Console (search.google.com/search-console)

| Что снять | Где именно |
|---|---|
| Запросы, страницы, показы, клики, CTR, позиция | Эффективность → Результаты поиска, период 3 месяца |
| Проиндексировано / не проиндексировано + причины | Индексирование → Страницы |
| Core Web Vitals по реальным пользователям | Основные интернет-показатели (отдельно Mobile и Desktop) |
| Статус карты сайта | Файлы Sitemap |

⛔ Если какой-то из панелей нет — это само по себе находка приоритета 1. Подключение занимает
20 минут, а без них вы управляете сайтом вслепую.

## Шаг 2. Краулинг сайта

**Инструмент:** Screaming Frog SEO Spider, бесплатной версии (500 URL) вам хватит с запасом.
**Обязательно включить рендеринг JavaScript:** Configuration → Spider → Rendering → JavaScript.
Без него Tilda отдаёт полупустые страницы, и отчёт будет ложным.

Что выгрузить (экспорт в CSV, можно положить в этот репозиторий — я разберу):

| Отчёт | Что ищем |
|---|---|
| Internal → All | коды ответа, глубина вложенности, размер страниц |
| Page Titles | дубли, пустые, длиннее 60 символов |
| Meta Description | дубли, пустые, длиннее 160 |
| H1 | отсутствующие, множественные |
| Images → Missing Alt Text | изображения без alt |
| Response Codes → Client Error (4xx) | битые ссылки |
| Response Codes → Redirection (3xx) | цепочки редиректов |
| Canonicals | отсутствующие и указывающие не на себя |
| Structured Data | найденная микроразметка и ошибки в ней |
| Internal → All Inlinks | сколько внутренних ссылок ведёт на каждую страницу |

Отдельно: отчёт Crawl Analysis → Orphan Pages — страницы, на которые не ведёт ни одна
внутренняя ссылка. Такая страница для поисковика почти не существует.

## Шаг 3. Частотность запросов — Яндекс.Wordstat

**wordstat.yandex.ru, регион «Россия».** Для каждого запроса снять три числа:

| Оператор | Что показывает |
|---|---|
| `английский детям` | базовая — вместе со всеми хвостами, завышена |
| `"английский детям"` | точная фраза во всех словоформах |
| `"!английский !детям"` | точная фраза без словоформ — самое честное число |

Список для проверки:

**Подтвердить или отклонить (решение ждёт этих цифр):**
- `английский без проблем` — если точная частотность близка к нулю, фраза остаётся слоганом, а не целью SEO

**Основные цели:**
- `онлайн школа английского языка`
- `английский детям`
- `английский школьникам`

**Кластер лицензии — ожидаю, что он окупится лучше всех:**
- `материнский капитал обучение английскому`
- `налоговый вычет за обучение ребёнка английскому`
- `курсы английского с лицензией для детей`

**Кембриджские уровни — решает, делать 8 страниц или одну:**
- `подготовка к KET`, `подготовка к PET`, `Cambridge Starters`, `Cambridge Movers`, `Cambridge Flyers`

Заодно смотреть левую колонку «Что искали со словом» — там видны реальные формулировки
родителей, которые стоит взять в тексты страниц дословно.

⛔ **Про сезонность.** В Wordstat есть вкладка «История запросов». Снимите её по основным
запросам: по базе оплат 51 % покупок приходится на август–октябрь (`product-marketing.md`, §12).
Если поисковый спрос совпадает с этим пиком, то работы по SEO надо закончить к июлю — позже
они не успеют дать эффект в сезон.

## Шаг 4. Скорость

**PageSpeed Insights (pagespeed.web.dev)** по трём URL: главная, страница курсов, статья блога.

Для каждого записать отдельно Mobile и Desktop:

| Показатель | Цель |
|---|---|
| LCP (отрисовка основного содержимого) | < 2,5 с |
| INP (реакция на действие) | < 200 мс |
| CLS (сдвиг макета) | < 0,1 |

⚠️ **Смотреть блок «Основные интернет-показатели» (полевые данные CrUX), а не только
лабораторную оценку.** Лабораторная — симуляция, полевые — то, что видят живые люди.
Если полевых данных нет, трафика пока мало для их сбора; тогда опирайтесь на лабораторные
и на Метрику: Отчёты → Мониторинг → Время загрузки страниц.

## Шаг 5. Микроразметка

По каждому типу страниц прогнать через **оба** валидатора:
- search.google.com/test/rich-results
- webmaster.yandex.ru/tools/microtest

Записать, какие типы найдены. Ожидаемый минимум: `EducationalOrganization`, `Course`,
`FAQPage`, `BreadcrumbList`. Чего нет — брать готовые блоки из `04-schema-jsonld.md`.

⚠️ Проверять только опубликованную страницу. Превью Tilda валидаторам недоступно.

## Шаг 6. Поведение людей — Яндекс.Метрика

Для Яндекса поведенческие факторы входят в ранжирование напрямую, поэтому это не «аналитика
на потом», а часть SEO.

| Что снять | Где |
|---|---|
| Отказы и глубина просмотра по страницам входа из органики | Отчёты → Содержание → Страницы входа, сегмент «Источник: поисковые системы» |
| Доля мобильного трафика | Отчёты → Технологии → Устройства |
| Карта скроллинга главной | Карты → Карта скроллинга |
| Записи визитов из органики | Вебвизор, фильтр по источнику |

⛔ Запись 2024 года о сайте: *«сложно скроллить»* (`product-marketing.md`, §15.8). Карта
скроллинга покажет, исправлено это или нет: если больше половины посетителей не доходит
до формы записи, дело не в трафике, а в странице.
