# SEO: аудит и материалы для fairwinds.school

Материалы SEO-аудита онлайн-школы Fair Winds. Сайт на Tilda — исходников в git нет,
поэтому все правки оформлены как готовые тексты для ручного переноса в интерфейс Tilda.

| Файл | Что внутри |
|---|---|
| `01-findings.md` | **Таблица поломок.** Раздел A — подтверждённые, с доказательствами. Раздел B — то, что не проверено, пока сайт закрыт сетевой политикой. |
| `02-keyword-map.md` | Карта «запрос → страница». Решения по исходному списку запросов и куда ушёл освободившийся ресурс. |
| `03-meta-texts.md` | Готовые title, description и H1 под вставку в Tilda. Длины проверены. |
| `04-schema-jsonld.md` | Блоки микроразметки JSON-LD. Синтаксис валиден, места для фактических данных помечены `ЗАПОЛНИТЬ`. |
| `05-audit-protocol.md` | Что именно снять и в каком отчёте какого сервиса. Ни одной цифры не выдумано. |
| `06-questions.md` | Вопросы, требующие решения владельца, с указанием, что каждый блокирует. |
| `data/` | Сюда класть выгрузки краулера и отчётов — я их разберу. |

## Статус

⛔ **Аудит неполный.** Домен `fairwinds.school` закрыт egress-политикой окружения
(`403 CONNECT`), поэтому проверить технику, скорость, заголовки, микроразметку и внутренние
ссылки на живом сайте не удалось. Порядок разблокировки — `05-audit-protocol.md`, шаг 0.

## Принцип

В этих файлах нет ни одной выдуманной цифры: ни позиций, ни частотности, ни числа учеников,
ни отзывов. Где данные нужны, но их нет, стоит пометка `⛔ ЗАПОЛНИТЬ` или указано,
какой показатель и в каком сервисе снять.
