# Готовые тексты для вставки в Tilda

**Как пользоваться.** В Tilda: «Настройки страницы → Основное → SEO». Поля `Заголовок страницы (title)`
и `Описание страницы (description)`. H1 ставится не здесь, а в самом Zero Block: выделить текстовый
элемент → в настройках выбрать тег `H1` (это отдельная настройка от размера шрифта).

**Ограничения по длине.** Title — до 60 символов, иначе обрежется в выдаче.
Description — до 160 символов. Длины ниже уже проверены, менять текст — пересчитывать.

⚠️ **Тексты написаны под целевую структуру из `02-keyword-map.md`.** Какие из этих страниц
существуют на сайте сегодня — я не знаю, домен закрыт. После разблокировки сверить со списком
реальных страниц: часть текстов пойдёт в дело сразу, часть — вместе с созданием страницы.

⛔ **Что я сознательно не написал.** Ни одной цифры о результатах учеников, ни одного отзыва,
ни одного «более 500 выпускников». У меня нет этих данных, а придуманные они хуже, чем никакие:
родитель проверяет такое первым делом.

## Главная

**Title (53):**
```
Онлайн-школа английского языка для детей | Fair Winds
```

**Description (144):**
```
Групповые занятия английским для детей 7-15 лет. Уроки полностью на английском, мини-группы, кембриджская программа. Первое занятие — бесплатно.
```

**H1:**
```
Онлайн-школа английского языка для детей и подростков
```

**Что изменилось против текущего.** Сейчас индексируется `Fair Winds - английский язык для детей и подростков`. Убран бренд с первой позиции — он не приносит трафика, пока вас не ищут по имени. Добавлены «онлайн-школа» и «языка» — это и есть целевой запрос. Бренд переехал в конец, где он выполняет ровно свою работу: помогает узнать вас тем, кто уже видел.

## Английский детям

URL: `/angliyskiy-detyam`

**Title (53):**
```
Английский детям онлайн — курсы 7-11 лет | Fair Winds
```

**Description (152):**
```
Курсы английского для детей 7-11 лет в мини-группах онлайн. Занятия целиком на английском, без зубрёжки. Кембриджская программа. Пробный урок бесплатно.
```

**H1:**
```
Английский детям онлайн — курсы для ребёнка 7–11 лет
```

**Обязательные блоки страницы:** формат занятий, размер группы, расписание, кто преподаёт, что ребёнок сможет через год, ответы на вопросы родителя, форма записи на пробное — и она должна быть видна без прокрутки до конца.

## Английский школьникам

URL: `/angliyskiy-shkolnikam`

**Title (58):**
```
Английский школьникам онлайн: курсы 11-15 лет | Fair Winds
```

**Description (145):**
```
Английский для школьников 11-15 лет онлайн. Подтянем школьную программу, снимем страх говорить, подготовим к экзаменам. Первое занятие бесплатно.
```

**H1:**
```
Английский школьникам онлайн — 11–15 лет
```

**Важно про интент.** Эта страница не повторяет предыдущую другими словами. Здесь родитель приходит с проблемой: «в школе тройки», «молчит на уроке», «скоро ОГЭ». Текст должен начинаться с этой проблемы, а не с рассказа о методике. Методика — дальше, как ответ.

## Шаблон для страниц кембриджских уровней

Подставить название уровня и возраст. Пример на KET:

**Title (56):**
```
Подготовка к Cambridge KET для детей онлайн | Fair Winds
```

**Description (135):**
```
Готовим детей 11-13 лет к кембриджскому экзамену KET (A2). Занятия в мини-группах онлайн, целиком на английском. Первый урок бесплатно.
```

**H1:**
```
Подготовка к Cambridge KET (A2) — детям 11–13 лет
```

⚠️ Перед тиражированием шаблона на все восемь уровней — снять частотность по каждому (`05-audit-protocol.md`, шаг 3). Уровни с нулевым спросом объединить в одну общую страницу «Кембриджская программа», иначе получите восемь полупустых страниц, которые тянут вниз оценку качества всего сайта.

## Правила, которые ломаются чаще всего

1. **Один H1 на страницу.** Не ноль и не три. В Zero Block ноль — частый случай: текст стоит обычным блоком.
2. **Title и H1 не обязаны совпадать.** Title работает в выдаче и борется за клик. H1 работает на странице и подтверждает, что человек попал куда надо. Они близки по смыслу, но формулируются по-разному.
3. **Description не влияет на позицию, но влияет на клик.** Поисковик может подставить вместо него кусок текста со страницы. Это не повод его не писать — хороший description подставляется чаще плохого.
4. **Уникальность.** Два одинаковых title на двух страницах — прямой сигнал дублирования. После правок прогнать краулером отчёт по дублям title и description.
5. **Не набивать ключами.** `Английский детям, английский для детей, курсы английского детям онлайн` в одном title — переспам. Он не поднимает, он опускает.
