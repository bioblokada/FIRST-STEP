# Карта запросов и страниц

**Правило документа.** Здесь нет ни одной цифры частотности и ни одной позиции — у меня их нет.
Есть распределение запросов по страницам и оценка достижимости, основанная на составе выдачи.
Частотность снимается вами по инструкции в `05-audit-protocol.md`, после чего приоритеты внутри
групп можно будет пересобрать по фактическим данным.

---

## Решение по исходному списку

| Запрос из брифа | Решение | Основание |
|---|---|---|
| онлайн школа английского языка | **Берём. Главная страница.** | Коммерческий запрос, точно описывает продукт. Конкуренция высокая, но это ваш профильный запрос — не брать его нельзя. |
| английский язык | **Снят с целей.** | Головной информационный частотник. В выдаче — Википедия, словари, Skyeng, Skysmart, Инглекс. Бюджеты на порядки выше вашего, домены старше. Даже при удачном стечении обстоятельств трафик по нему нецелевой: человек, набравший «английский язык», чаще ищет перевод или грамматику, а не платный курс для ребёнка. Решение согласовано. |
| английский детям | **Берём. Отдельная страница курса.** | Коммерческий, точно бьёт в ваш продукт (7–15 лет). Ядро всего проекта. |
| английский школьникам | **Берём. Отдельная страница.** | Близко к предыдущему, но другой интент: школьник = помощь со школьной программой, оценки, подтягивание. Не смешивать со страницей «детям», иначе получим каннибализацию — две страницы будут конкурировать друг с другом за один запрос и обе просядут. |
| английский без проблем | **На паузе до проверки Wordstat.** | Подтверждено в разговоре: это предположение, что фразу ищут, а не данные. Проверка занимает 15 минут — инструкция в `05-audit-protocol.md`, шаг 3. До неё страницу не делать. |

## Куда уходит освободившийся ресурс

Вместо одного недостижимого головного запроса — группы, где вы конкурентоспособны
из-за узкой специализации. Общее правило: чем точнее запрос описывает именно ваш
продукт, тем дешевле по нему вырасти.

### Группа 1 — Главная страница

Основной запрос: `онлайн школа английского языка`
Поддерживающие: `онлайн школа английского для детей`, `английский онлайн для детей школа`, `школа английского языка онлайн для ребёнка`

Задача страницы: объяснить, что это за школа, для кого, чем отличается, и довести до бесплатного пробного занятия.

### Группа 2 — Страница `/angliyskiy-detyam` (или существующий аналог)

Основной запрос: `английский детям`
Поддерживающие: `английский язык для детей онлайн`, `курсы английского для детей`, `английский для детей 7 лет`, `английский для ребёнка с нуля`, `онлайн курсы английского для детей`

Интент: родитель ребёнка 7–10 лет, английского либо нет вообще, либо только школьный.

### Группа 3 — Страница `/angliyskiy-shkolnikam`

Основной запрос: `английский школьникам`
Поддерживающие: `английский для школьников онлайн`, `английский для подростков`, `репетитор английского для школьника онлайн`, `подтянуть английский школьнику`

Интент другой, чем в группе 2: не «начать», а «исправить». Ребёнок 11–15 лет, в школе проблемы или скучно. Текст страницы должен говорить про школьную программу, оценки и уверенность на уроке, а не про «весёлые занятия».

### Группа 4 — Кембриджские уровни (8 потенциальных страниц)

Ваша линейка Pre-Starters → Starters → Movers 1–7 → Flyers → KET → PET → Pre-FCE → CAE — это готовая структура посадочных страниц.

| Страница | Основной запрос | Кому |
|---|---|---|
| `/pre-starters` | `английский для детей 7 лет с нуля` | первый контакт с языком |
| `/starters` | `подготовка к Cambridge Starters` | 7–9 лет |
| `/movers` | `подготовка к Cambridge Movers` | 9–11 лет |
| `/flyers` | `подготовка к Cambridge Flyers` | 10–12 лет |
| `/ket` | `подготовка к KET для детей` | 11–13 лет |
| `/pet` | `подготовка к PET для подростков` | 12–14 лет |
| `/fce` | `подготовка к FCE для подростков` | 13–15 лет |
| `/cae` | `подготовка к CAE` | продвинутые |

Конкуренция здесь заметно ниже, чем в группах 1–3, а посетитель приходит уже понимающий, чего хочет. Начинать с тех уровней, где у вас больше всего учеников: там вы точно знаете, что писать, и есть кого просить об отзыве.

⚠️ Перед тем как делать все восемь — снять частотность по каждому. Часть уровней может оказаться с нулевым спросом, тогда объединить их в одну страницу «Кембриджская программа».

### Группа 5 — Лицензия, маткапитал, налоговый вычет

`/oplata-matkapitalom` или `/litsenziya-i-vychet`

Запросы: `оплатить обучение английскому материнским капиталом`, `налоговый вычет за курсы английского для ребёнка`, `онлайн школа английского с лицензией`, `курсы английского с лицензией для детей`

**Это самая недооценённая группа в списке.** Лицензия подтверждена платежом от 20.12.2024 (`product-marketing.md`, §15.4), оплаты маткапиталом в базе уже есть. У большинства онлайн-школ английского лицензии нет, поэтому конкуренция за эти запросы слабая — а посетитель приходит с готовым решением и деньгами. Плюс это прямой ответ на возражение «дорого» (§15.6): вычет 13 % + маткапитал снимают около четверти цены.

### Группа 6 — Информационный блог, который ведёт в продажу

Не для прямых продаж, а для верхней части воронки и для наращивания тематической массы сайта. Каждая статья обязана содержать 2–3 контекстные ссылки на профильную коммерческую страницу — иначе она бесполезна (см. `01-findings.md`, раздел B, «Внутренняя перелинковка»).

Темы, вырастающие из вашей же фактуры:
- уровни английского для детей — **статья уже есть**, нужно довести URL и перелинковку
- со скольки лет учить ребёнка английскому
- как понять уровень английского у ребёнка
- чем групповые занятия отличаются от занятий с репетитором
- что такое кембриджские экзамены и зачем они ребёнку
- почему урок целиком на английском работает, если ребёнок ничего не понимает — это ваша методика и ваше отличие
- как выбрать онлайн-школу английского для ребёнка

⛔ Последняя тема — формат «как выбрать» — притягивает людей в момент выбора. Но писать её честно: список критериев, по которым вы объективно сильны (мини-группы, погружение, кембриджская линейка, лицензия). Не подгонять критерии под себя так, чтобы победить могли только вы, — читатель это чувствует.

---

## Правило против каннибализации

Одна страница = один основной запрос. Если две страницы бьют в один запрос, поисковик
выбирает между ними сам и обычно выбирает хуже, чем выбрали бы вы, — а вес делится пополам.

Перед публикацией любой новой страницы: проверить по этому файлу, не занят ли основной запрос
уже существующей страницей. Если занят — либо усиливать существующую, либо менять интент новой.
